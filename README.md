# Northstar - Product Catalogue UI

A responsive storefront interface built with semantic HTML, CSS and vanilla JavaScript.

## Live demo
https://aditya-northstar-storefront.vercel.app

## Features
- Search products by name or category
- Filter by category
- Sort by price (ascending or descending)
- Add products to a cart counter
- Responsive product grid
- DOM elements are created with text-safe APIs

## Run locally
Open `index.html` in a modern browser. No build step or dependencies are required.

## Scope and limitations
This is a front-end demo with sample product data. It does not include checkout, payment processing, authentication, persistent cart storage or a backend.
